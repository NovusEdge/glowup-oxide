# oxide

A light [glowup](https://github.com/NovusEdge/glowup) pack: warm ink and red oxide on bone paper, with the dotted `orb-states` spinner standing in for a dither shader. Tool colors are the riso blue, auburn, olive and goggle teal from the reference images, darkened until each one reads at 3:1 or better on the background.

## Install

```
/glowup pack https://raw.githubusercontent.com/NovusEdge/glowup-oxide/main/oxide.json
```

The pack is drawn for a bone background, `#ddd6c8`. On a dark terminal the text is near-black and hard to read, so set your terminal background to `#ddd6c8` first. In Konsole, `/glowup export konsole` writes a matching color scheme.
